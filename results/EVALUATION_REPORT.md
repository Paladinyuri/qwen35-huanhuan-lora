# Qwen3.5-4B Chat-嬛嬛 LoRA 实验结果

本次实验只用去重后的 2,887 条训练数据更新参数，371 条验证数据用于选择 checkpoint，359 条测试数据没有参与训练。相同用户问题不会跨集合出现。

## 训练结果

rank 32 模型训练 2 个 epoch。第 2 轮训练 loss 继续下降，但验证 loss 上升，因此固定评估采用 epoch 1 checkpoint。

| Epoch | 训练 loss | 验证 loss |
| ---: | ---: | ---: |
| 1 | 3.3684 | **3.2996** |
| 2 | **2.7133** | 3.3886 |

## 60 条分类评估

测试集包含角色与关系、宫廷情境、开放表达、通用知识、抗提示覆盖、安全与诚实六类，每类 10 条。基座和 LoRA 使用相同 system prompt、temperature=0、seed=42 和 max_tokens=160。

| 指标 | 基座模型 | rank 32 LoRA |
| --- | ---: | ---: |
| 平均回复字符数 | 201.7 | 38.6 |
| 风格词命中率 | 70.0% | 41.7% |
| 达到长度上限 | 81.7% | 8.3% |
| 高重复回答 | 0% | 10.0% |
| 与训练答案完全一致 | 0 | 5 |
| 与训练答案高度相似 | 0 | 5 |

LoRA 显著减少了基座模型的大段舞台描写和长度截断，在数学、基础常识和短句角色对话中通常更直接。但 60 条测试也表明，短回答并不等于高质量：部分问题被“臣妾不敢”等套话回避，并出现人物关系事实错误。

## 记忆与重复

评估会为每个生成结果检索最相似的训练答案，同时报告字符序列相似度和 3-gram Jaccard。rank 32 有 5/60 条回答与训练答案完全相同，高重复回答占 10%。典型重复包括连续生成“海棠花”“点点滴滴”“没有牵挂”等短语。

降低 rank 没有消除这一问题：rank 8、16 同样各有 5 条完全复述，重复率还略高。详细对比见 [`ABLATION_REPORT.md`](ABLATION_REPORT.md)。

## 安全与事实性失败

- 对持续胸痛回答“忍一忍”，可能延误就医；
- 没有明确阻止用户提供银行卡密码；
- 对忘记药物剂量的问题生成未经验证的剂量逻辑；
- 把流朱说成眉庄的侍女，人物关系事实错误；
- 对部分开放问题只回答“臣妾不敢”，相关性不足。

这些失败说明角色数据会覆盖一部分基座模型原有的谨慎回答模式。当前模型不能用于医疗、金融、账户安全或其他高风险建议。

## 结论

干净重训支持的结论是：LoRA 显著改变了回答长度和表达形式，使输出更接近短台词，但也带来训练语句复述、循环生成、事实错误和安全回答退化。自动指标尚不能证明整体对话质量提升。
